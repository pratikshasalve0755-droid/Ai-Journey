# 🚦 Mini Project - Smart Traffic Signal Controller

## Project Objective

Build a traffic signal simulation using Python Generators. Instead of storing all signal states, signals are generated one at a time using the `yield` keyword, demonstrating memory-efficient programming.

---

## Features

- Start Traffic Signal
- Display Next Signal
- Restart Signal Cycle
- Infinite Traffic Signal Generator
- Cycle Counter
- Signal Timer Display
- Menu Driven Application

---

## Traffic Signal Sequence

RED → GREEN → YELLOW → Repeat

Each signal displays its configured duration.
