# Practice 1 - Student Roll Iterator

## Objective

Learn how Python Iterators work by manually iterating through student roll numbers using `iter()` and `next()`.

## Concepts Covered

- Iterable
- Iterator
- iter()
- next()
- StopIteration Exception

## Files

- main.py

## Features

- Store student roll numbers
- Convert list into an iterator
- Retrieve one roll number at a time
- Handle StopIteration gracefully

## Learning Outcome

This practice helped me understand that iterators allow sequential access to data one element at a time without using indexing or loops directly.
