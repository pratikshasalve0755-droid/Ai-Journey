# Practice 2 - Number Generator

## Objective

Learn how generator functions create values one at a time using the `yield` keyword.

## Concepts Covered

- Generator Functions
- yield
- next()
- Memory Efficient Programming

## Files

- main.py

## Features

- Generate numbers between a given range
- Produce one value at a time
- Avoid storing all numbers in memory

## Learning Outcome

This practice demonstrated how generators produce values lazily, making programs faster and more memory efficient.
