# Practice 1 – Greeting Decorator

## 📌 Objective

Learn the fundamentals of Python decorators by creating a simple decorator that adds a greeting message before executing a function.

---

## 📚 Concepts Covered

- Functions as First-Class Objects
- Nested Functions
- Returning Functions
- Basic Decorators
- @decorator Syntax

---

## 🛠 Features

- Displays a greeting message before executing the original function.
- Demonstrates how decorators wrap existing functions.
- Shows code reusability without modifying the original function.

---

## ▶ Example Output

```
Welcome to the Program!

Hello, Python Learner!
```

---

## 🎯 Learning Outcome

By completing this practice, I understood:

- What decorators are.
- Why decorators are useful.
- How a decorator wraps another function.
- How the `@decorator` syntax works.
