# Practice 2 – Login Authentication Decorator

## 📌 Objective

Understand how decorators can be used for authentication before allowing access to protected functions.

---

## 📚 Concepts Covered

- Decorators
- Authentication Logic
- Nested Functions
- Conditional Execution
- Code Reusability

---

## 🛠 Features

- Checks whether a user is logged in.
- Allows execution only after successful authentication.
- Prevents unauthorized access to protected functions.
- Demonstrates real-world usage of decorators.

---

## ▶ Example Output

```
Please Login First!

Login Successful!

Verification Successful!

Welcome User!
```

---

## 🎯 Learning Outcome

Through this practice, I learned:

- How decorators improve security.
- How authentication decorators work.
- How to reuse login verification across multiple functions.
- Real-world use cases of decorators.
