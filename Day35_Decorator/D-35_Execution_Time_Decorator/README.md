# Practice 3 – Execution Time Decorator

## 📌 Objective

Measure how long a function takes to execute using a custom decorator.

---

## 📚 Concepts Covered

- Decorators
- time Module
- Performance Monitoring
- Function Wrapping

---

## 🛠 Features

- Records start time.
- Executes the original function.
- Calculates execution time.
- Displays total execution duration.

---

```
Program Started...

Task Completed!

Execution Time:
0.00231 seconds
```
