# Mini Project: Smart Online Exam System

## 📌 Project Overview

The Smart Online Exam System is a console-based Python application that simulates an online examination platform.

The project demonstrates the practical use of Python Decorators by implementing login authentication before allowing users to access the exam.

Users must log in successfully, answer multiple-choice questions, and view their results after completing the exam.

---

## 🚀 Features

- 🔐 Secure Login Authentication
- 🎯 Custom Python Decorator (@login_required)
- 📝 Multiple Choice Questions (MCQ)
- ✅ Automatic Answer Validation
- 📊 Marks Calculation
- 🏆 Pass / Fail Result
- 👤 Student Result Display
- ⚠️ Input Validation
- 📋 Menu Driven Interface
