# 📱 Smart Contact Information Extractor

## 📌 Overview

The **Smart Contact Information Extractor** is a Python-based mini-project created to demonstrate the practical use of **Regular Expressions (Regex)**.

The program accepts text from the user and provides different operations such as:

- Entering text
- Extracting email addresses
- Extracting phone numbers
- Viewing extracted information
- Cleaning text
- Exiting the application

This project combines multiple Regex concepts into a single menu-driven application.

---

## 🎯 Project Objective

The main objective of this project is to understand how Regular Expressions can be used for **real-world text processing and information extraction**.

The project focuses on:

- Pattern matching
- Information extraction
- Text cleaning
- Input validation
- Menu-driven programming
- List management
- Functions
- `re.findall()`
- `re.sub()`
