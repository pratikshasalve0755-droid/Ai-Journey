# 📧 Practice 2 — Email Extractor

## 📌 Overview

This practice project demonstrates how **Regular Expressions (Regex)** can be used to identify and extract email addresses from text.

The program accepts text from the user and searches for email addresses using Python's built-in `re` module.

---

## 🎯 Objectives

The main objectives of this practice are:

- Understand Regex-based pattern matching.
- Learn how to identify email patterns.
- Use `re.findall()` for extracting multiple emails.
- Understand character classes and quantifiers.
- Store extracted emails in a list.
- Display extracted email addresses clearly.

---

## 🛠️ Technologies Used

- Python
- `re` (Regular Expression) module
