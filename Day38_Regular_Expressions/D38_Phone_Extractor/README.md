# 📱 Practice 1 — Phone Number Extractor

## 📌 Overview

This practice project is created to learn the basics of **Regular Expressions (Regex)** in Python.

The program takes text as input and searches for **10-digit phone numbers** using Python's built-in `re` module.

It demonstrates how Regex can be used to extract specific patterns from unstructured text.

---

## 🎯 Objectives

The main objectives of this practice are:

- Understand the basics of Regular Expressions.
- Learn how to use Python's `re` module.
- Use `re.findall()` to search for multiple matches.
- Extract phone numbers from text.
- Understand Regex patterns and special characters.
- Display multiple extracted phone numbers using `enumerate()`.

---

## 🛠️ Technologies Used

- Python
- `re` (Regular Expression) module
