# 🧹 Practice 3 — Text Cleaner

## 📌 Overview

This practice project demonstrates how **Regular Expressions** can be used to clean unwanted characters from text.

The program accepts text from the user and removes unwanted special characters using Python's `re.sub()` function.

---

## 🎯 Objectives

The main objectives of this practice are:

- Understand Regex-based text cleaning.
- Learn how to use `re.sub()`.
- Identify unwanted characters using Regex.
- Replace unwanted characters with an empty string.
- Understand character classes and negation.
- Perform basic text preprocessing.

## 🛠️ Technologies Used

- Python
- `re` (Regular Expression) module
