# 📊 Practice 3 — API Data Analyzer

## 📌 Overview

This practice project demonstrates how API data can be retrieved, processed, and analyzed using Python.

The program sends a request to an API, checks whether the request was successful, converts the response into JSON, extracts required information, and displays useful results.

This practice combines API communication with Python data processing.

---

## 🎯 Objectives

The main objectives of this practice are:

- Send API requests.
- Check API response status.
- Process JSON responses.
- Extract required information.
- Analyze API data.
- Display information in a readable format.
- Handle basic API errors.
- Combine multiple Python concepts into one program.

---

## 🛠️ Technologies Used

- Python
- `requests` library
- JSON
- Functions
- Conditional Statements
- Exception Handling
- Lists and Dictionaries
