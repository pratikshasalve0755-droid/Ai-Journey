# 📡 Practice 1 — Basic API Request

## 📌 Overview

This practice project introduces the fundamentals of **APIs (Application Programming Interfaces)** in Python.

The program sends a GET request to an API using Python's `requests` library and examines the response returned by the server.

This is the first step toward learning how Python applications communicate with external services.

---

## 🎯 Objectives

The main objectives of this practice are:

- Understand what an API is.
- Understand how a client communicates with a server.
- Learn the basics of HTTP requests.
- Learn how to use the `requests` library.
- Send a GET request using `requests.get()`.
- Understand API response objects.
- Learn about HTTP status codes.
- Display the response returned by an API.

---

## 🛠️ Technologies Used

- Python
- `requests` library
- REST API
- HTTP
