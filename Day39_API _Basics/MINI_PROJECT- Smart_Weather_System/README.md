# 🌤️ Smart Weather Information System

## 📌 Overview

The **Smart Weather Information System** is a Python-based mini-project created to demonstrate the practical use of **APIs, HTTP requests, JSON data, functions, and exception handling**.

The application allows the user to search for weather information and displays the retrieved data in a simple and readable format.

The project demonstrates how a Python application can communicate with an external service and process real-world data.

---

## 🎯 Project Objective

The main objective of this project is to understand how APIs work in real-world applications.

The project focuses on:

- API communication
- HTTP GET requests
- JSON responses
- Data extraction
- Error handling
- Functions
- Menu-driven programming
- User input
- Processing external data

---

## 🛠️ Technologies Used

- Python
- `requests` library
- REST API
- JSON
- Functions
- Lists and Dictionaries
- Exception Handling
