# 🎓 Mini Project - Smart Student Database System

## Project Objective

Build a Student Database System that stores student records permanently using JSON files. The application allows users to manage student information through a menu-driven interface.

---

## Features

- Add Student
- View All Students
- Search Student by ID
- Update Student Information
- Delete Student
- Permanent Data Storage using JSON

---

## Student Details

Each student record contains:

- Student ID
- Name
- Age
- Course
- City

---

## Technologies Used

- Python
- JSON Module
- File Handling
- Functions
- Exception Handling
- Lists & Dictionaries
