# Practice 1 — Basic Threading

## 📌 Objective

The objective of this practice is to understand the basic concept of creating and running a thread in Python.

## 🧠 Concepts Learned

- What is a Thread?
- Python `threading` module
- Creating a Thread
- `target` parameter
- `start()` method
- `join()` method
- Executing a function using a thread
- Basic thread execution flow

## 🔧 Technologies Used

- Python
- `threading`
- `time`

## 📚 What I Practiced

In this practice, I created a simple task function and executed it using a separate thread.

The basic flow was:

Function  
↓  
Create Thread  
↓  
Start Thread  
↓  
Thread Executes Function  
↓  
Join Thread  
↓  
Main Program Continues

## 🎯 Key Learning

I learned that a thread allows a function to execute independently within a Python program.

I also learned that:

- `start()` begins thread execution.
- `join()` makes the main program wait for the thread to finish.
- A thread can be created by providing a function as its `target`.

## 🚀 Outcome

Successfully created and executed my first basic Python thread and understood the fundamental workflow of multithreading.
