# 🚀 Smart Multi-Task Data Processor

## 📌 Project Overview

Smart Multi-Task Data Processor is a Python-based mini project created to demonstrate the practical use of multithreading.

The project performs multiple independent tasks and allows the user to execute them either sequentially or using multiple threads.

The project also measures and displays execution time.

## 🎯 Objective

The main objective of this project is to understand:

- Multithreading
- Sequential execution
- Concurrent execution
- Thread creation
- Thread synchronization
- Execution-time measurement
- Program state management

## 🧠 Concepts Used

- Python Functions
- `threading` module
- `Thread` class
- `start()`
- `join()`
- `time` module
- `time.perf_counter()`
- Exception Handling
- Menu-driven programming
- Sequential execution
- Multithreading

## ⚙️ Tasks Performed

The project contains three tasks:

### 1. Collecting Data

Generates numbers from 1 to 5 with a small delay between each operation.

### 2. Processing Data

Processes and displays vowels:
