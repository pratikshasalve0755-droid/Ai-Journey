# 📊 Mini Project – Smart Data Cleaning & Analysis System

## 📌 Description

The **Smart Data Cleaning & Analysis System** is a Python-based mini project that processes messy student data and converts it into useful information.

Real-world data is often incomplete or messy. Before performing analysis, the data needs to be cleaned.

This project demonstrates the basic process of:

**Raw Data → Data Cleaning → Data Processing → Data Analysis**

---

## 🎯 Objectives

The main objectives of this project are:

- Clean incomplete student records
- Remove students with empty names
- Identify passing students
- Generate student grades
- Identify top-performing students
- Calculate basic marks statistics
- Practice List Comprehension with real-world data

---

## 🧠 Concepts Used

- Lists
- Dictionaries
- List Comprehension
- Conditional Expressions
- Functions
- Loops
- `if-elif-else`
- Exception Handling
- `sum()`
- `max()`
- `min()`
- Basic Data Cleaning
- Basic Data Analysis
