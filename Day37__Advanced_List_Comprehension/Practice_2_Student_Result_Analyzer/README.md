# 🎓 Practice 2 – Student Result Analyzer

## 📌 Description

This practice program analyzes student marks using **List Comprehension** and conditional expressions.

It determines student results based on their marks.

---

## 🎯 Objective

The main objectives are:

- Practice List Comprehension
- Work with lists and dictionaries
- Apply conditions to student data
- Analyze student results
- Generate results efficiently

---

## 🧠 Concepts Used

- Lists
- Dictionaries
- List Comprehension
- Conditional expressions
- `if-else`
- Functions
- Loops

---

## ⚙️ How It Works

The program:

1. Stores student information.
2. Reads the marks of each student.
3. Checks the marks using conditions.
4. Determines whether the student passed or failed.
5. Displays the result.

---

### Input

Student Marks:
