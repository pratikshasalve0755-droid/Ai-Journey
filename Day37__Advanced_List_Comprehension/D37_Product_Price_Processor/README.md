# 🛒 Practice 3 – Product Price Processor

## 📌 Description

This practice program processes product prices using **List Comprehension**.

It demonstrates how Python can be used to transform and analyze a collection of product prices.

---

## 🎯 Objective

The main objectives are:

- Practice List Comprehension
- Process product prices
- Apply calculations to list elements
- Filter data based on conditions
- Understand data transformation

---

## 🧠 Concepts Used

- Lists
- Dictionaries
- List Comprehension
- Conditional expressions
- Mathematical operations
- `for` loops

---

## ⚙️ How It Works

The program:

1. Stores product information.
2. Extracts product prices.
3. Processes the prices using List Comprehension.
4. Applies the required calculation or filtering.
5. Displays the processed product data.
