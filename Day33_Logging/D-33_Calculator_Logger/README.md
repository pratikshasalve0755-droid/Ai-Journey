# Practice 2 - Calculator Logger

## Objective

Build a calculator that records every mathematical operation into a log file.

## Concepts Covered

- Logging Module
- INFO Log Level
- ERROR Log Level
- Exception Handling
- Arithmetic Operations

## Files

- main.py
- calculator.log

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by Zero Handling
- Store every operation in a log file

## Learning Outcome

This practice helped me understand how logging can be used to record user activities and application errors in real-world software.
