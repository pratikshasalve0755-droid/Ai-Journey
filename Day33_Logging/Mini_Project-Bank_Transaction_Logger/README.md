# 🏦 Mini Project - Smart Bank Transaction Logger

## Project Objective

Build a banking application that records every important transaction using Python's logging module. The project demonstrates how professional applications monitor activities and maintain log files for debugging and auditing.

---

## Features

- Deposit Money
- Withdraw Money
- Check Account Balance
- Input Validation
- Insufficient Balance Detection
- Exception Handling
- Automatic Log File Generation

---

## Log Levels Used

- INFO
- WARNING
- ERROR

---

## Technologies Used

- Python
- Logging Module
- Object-Oriented Programming (OOP)
- Encapsulation
- Exception Handling
