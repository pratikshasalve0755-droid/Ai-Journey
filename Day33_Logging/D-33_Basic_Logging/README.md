# Practice 1 - Basic Logging

## Objective

Learn how to use Python's built-in `logging` module to record application events instead of using print statements.

## Concepts Covered

- logging module
- logging.basicConfig()
- Log Levels
- INFO messages
- Log File Creation

## Files

- main.py
- app.log

## Features

- Configure logging
- Record program start
- Record user login
- Record user logout
- Record program exit
- Save logs into a file

## Learning Outcome

After completing this practice, I understood how Python applications keep a permanent record of important events using log files, making debugging and monitoring much easier.
