# Practice 3 - Login Attempt Logger

## Objective

Learn how applications record login attempts and security-related events using different logging levels.

## Concepts Covered

- INFO
- WARNING
- CRITICAL
- Login Validation
- Security Logging

## Files

- main.py
- login.log

## Features

- User Login
- Password Validation
- Successful Login Logging
- Failed Login Logging
- Three Failed Attempts Detection
- Critical Log Generation

## Learning Outcome

After completing this practice, I learned how login systems monitor user authentication attempts and maintain security logs for future analysis.
