# Practice 2 - Employee Salary Filter

## 📌 Objective

Learn how to use Python's `filter()` function with a lambda expression to select specific data from a list.

---

## 📚 Concepts Used

- Lambda Function
- filter()
- Lists

---

## 💡 Description

This program stores employee salaries and filters only those employees whose salary is greater than ₹30,000.

---

## 🚀 Features

- Stores salary values
- Filters premium salaries
- Displays filtered results

---

## 🎯 Learning Outcome

- Learned how `filter()` selects elements based on a condition.
- Understood how lambda functions make filtering simple.
- Improved logical thinking using functional programming.
