# Practice 1 - Student Marks Calculator

## 📌 Objective

Learn how to use Python's `map()` function along with a `lambda` function to modify every element in a list.

---

## 📚 Concepts Used

- Lambda Function
- map()
- Lists

---

## 💡 Description

This program stores a list of student marks and uses the `map()` function with a lambda expression to add bonus marks to every student's score.

---

## 🚀 Features

- Stores student marks in a list
- Adds bonus marks using `map()`
- Displays original marks
- Displays updated marks

---

## 🎯 Learning Outcome

- Understood how `map()` applies a function to every element of a list.
- Learned how lambda functions can simplify small operations.
- Improved understanding of functional programming in Python.
