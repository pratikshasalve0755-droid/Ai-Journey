# Practice 3 - Product Bill Generator

## 📌 Objective

Learn how to calculate a single result from multiple values using Python's `reduce()` function.

---

## 📚 Concepts Used

- Lambda Function
- reduce()
- functools Module
- Lists

---

## 💡 Description

This program stores product prices in a list and calculates the total bill amount using the `reduce()` function.

---

## 🚀 Features

- Stores product prices
- Calculates total bill
- Displays final amount

---

## 🎯 Learning Outcome

- Learned how `reduce()` combines multiple values into a single result.
- Understood why the `functools` module is required.
- Improved understanding of functional programming concepts.
