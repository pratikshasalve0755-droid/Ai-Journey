# 🛒 Mini Project – Smart Shopping Cart System

## 📌 Objective

Build a menu-driven shopping cart application using Python's functional programming concepts.

---

## 📖 Description

This application allows users to add products, view products, calculate discounted prices, filter premium products, and generate the final shopping bill.

The project demonstrates practical usage of **lambda**, **map()**, **filter()**, and **reduce()**.

---

## 🚀 Features

- Add Products
- View Products
- Apply 10% Discount using map()
- Filter Premium Products using filter()
- Generate Final Bill using reduce()
- Menu Driven Interface
- Input Validation
- Dictionary-Based Data Storage

---

## 📂 Menu

1. Add Product
2. View Products
3. Show Discounted Prices
4. Show Premium Products
5. Generate Final Bill
6. Exit
